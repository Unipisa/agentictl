# Quickstart

This file is kept for existing links. New users should start with:

[GETTING_STARTED.md](GETTING_STARTED.md)

The short version:

1. Install the OpenClaw skill folder.
2. Install the local skill helper tools.
3. Generate read-only and action SSH keys.
4. Install node-side `agentictl` with `install/install-node.sh`.
5. Configure SSH aliases such as `node-ro` and `node-act`.
6. Verify `ssh node-ro health`.
7. Ask OpenClaw to use `/agentictl_ssh`.
